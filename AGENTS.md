# Project conventions
- Theme palettes are defined in the central theme engine, which derives every surface and contrast token for the selected appearance mode; this keeps theme changes consistent throughout the app.
- Shared visual styling uses global semantic tokens and existing forwardRef controls; this preserves theming and animation compatibility.
- The homepage prioritizes featured play and the game library, with secondary discovery sections behind the existing expansion control; this keeps games easy to reach.
- Payment overlays only enter success after server verification; client-owned, cleaned-up timers sequence the tick, clipped vector character and dismissal without changing payment grants.
